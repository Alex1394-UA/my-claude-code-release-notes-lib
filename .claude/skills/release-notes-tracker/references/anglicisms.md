# Словник анґліцизмів та замін

Патерн: англійський корінь + українське закінчення через дефіс (напр. "invoke-є", "match-или").
Такі конструкції неприродні — заміняйте на правильні українські дієслови або перефразовуйте.

## Прийняті Ukr IT-позички (НЕ виправляти)

Ці слова вже увійшли в українську IT-термінологію — вважаються нормою:
- кешувати, кеш, кешування
- клонувати, клон
- форкнути, форк, форкання
- парсити, парсинг
- рендерити, рендер, рендеринг
- крашити, краш
- блокувати, блок
- скіпати (рідко, краще "пропускати")
- монтувати, маунт

## Як шукати

Grep патерн для пошуку:
```
\w+-\w*[іїэєи]{1,2}(ся)?
```
Але цей патерн дає багато false positives. Практичніше шукати конкретні відомі анґліцизми з таблиць вище.

Для автоматичного пошуку в `docs/kb/categories/`:
```bash
grep -rnP '\b(invoke|match|strip|drop|skip|trigger|report|track|sync|merge|flush|fetch|parse|render|stream|resolve|retry|load|dump|scope|stage|batch|route|proxy|reset|mount|spawn|loop|wrap|fallback|worker|daemon|crash|fix|break|catch|pass|push|pull|cache|block)-[а-яіїєґ]+(ся)?\b' docs/kb/categories/
```
