# Реліз 2.1.207 — 2026-07-26

## Нові можливості

- Auto mode тепер доступний без `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in на Bedrock, Vertex AI та Foundry; вимикається через `disableAutoMode` в settings

## Виправлення

- Виправлено зависання термінала та відставання натискань клавіш під час стрімінгу відповідей з дуже довгими списками, таблицями, абзацами або блоками коду
- Виправлено remote managed settings з non-interactive запуску (`claude -p`, SDK) що назавжди записувались як погоджені без показу security consent dialog
- Виправлено хибні prompt-injection попередження що спрацьовували від безпечних system-generated оновлень розмови
- Виправлено auto-updater що перезаписував custom launcher script або symlink у `~/.local/bin/claude` на кожному релізі; `/doctor` тепер повідомляє про externally managed launcher
- Виправлено compound commands з `cd` що просили permission коли єдиним перенаправленням виводу був до `/dev/null`
- Виправлено стрибок транскрипту вище початку відповіді після завершення стрімінгу
- Виправлено `extensions.worktreeConfig` що залишався в `.git/config` репозиторію (ламаючи go-git інструменти як `tea`) після видалення останнього `worktree.sparsePaths` worktree
- Виправлено malformed bracket patterns в rules globs, skill paths, `.ignore` та `.worktreeinclude` що ламали file reads, suggestions та worktree creation
- Виправлено crash loop в agent teams коли malformed teammate mailbox message викликав repeated errors щосекунди до ручного видалення mailbox file
- Виправлено background sessions що автоматично називались прийняттям плану але не показували це ім'я на рядку agent-view
- Виправлено background sessions що увійшли в git worktree та відновлювались порожніми після cold reopen з agent list
- Виправлено Remote Control task status updates що втрачались коли з'єднання відновлювалось після network interruption або credential refresh
- Виправлено Remote Control sessions hosted by desktop app що не показували background agent та workflow progress на mobile та web
- Виправлено Deep research runs що позначали кожного Fetch-phase agent як «unknown» — chips тепер показують source hostname
- Виправлено Bedrock що постійно запитував нові AWS SSO credentials з IAM Identity Center на кожному API request
- Виправлено indefinite hang на Windows коли AWS credential resolution stalls (stuck `credential_process`); 60-second stall guard тепер спрацьовує замість нескінченного очікування
- Plugin hooks/monitors/MCP headersHelper: `${user_config.*}` в shell-form commands тепер відхиляється (shell-injection fix); hooks: використовуйте exec form (`args` array) або `$CLAUDE_PLUGIN_OPTION_<KEY>`; monitors та headersHelper: читайте значення всередині скрипта
- Виправлено `/usage-credits` amount inputs що мовчки обрізали malformed values до цифр; malformed amounts тепер відхиляються з помилкою, а суми понад $1,000 вимагають підтвердження вводом з клавіатури

## Важливі зміни

- Bedrock, Vertex та Claude Platform on AWS тепер за замовчуванням використовують Claude Opus 4.8
- Auto mode більше не читає `autoMode` з `.claude/settings.local.json` (repo-resident); використовуйте `~/.claude/settings.json`
- Plugin option values (`pluginConfigs`) більше не читаються з project-level `.claude/settings.json`; лише user, `--settings` та managed settings враховуються

- Agent view: blocked session peeks тепер починаються з питання та показують worded staleness clock (`waiting 3m`) замість того ж timestamp двічі
