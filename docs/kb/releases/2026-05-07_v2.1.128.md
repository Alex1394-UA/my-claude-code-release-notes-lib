- Bare `/color` без аргументів підбирає випадковий колір (core)
- `/mcp` показує кількість інструментів для підключених серверів та позначає 0-tool servers (mcp)
- `--plugin-dir` приймає `.zip` plugin archives крім директорій (plugins, cli)
- `--channels` працює з console (API key) аутентифікацією (cli)
