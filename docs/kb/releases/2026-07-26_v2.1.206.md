# Реліз 2.1.206 — 2026-07-26

## Нові можливості

- `/cd` тепер пропонує шляхи директорій як `/add-dir`
- `/doctor` тепер пропонує скоротити checked-in `CLAUDE.md` файли, вилучаючи контент що Claude може вивести з кодової бази
- `/commit-push-pr` тепер автоматично дозволяє `git push` до налаштованого push remote (`remote.pushDefault`, або єдиного remote коли лише один) на додачу до `origin`
- `/login` тепер підтримує Anthropic-operated public gateway endpoints
- `EnterWorktree` тепер запитує підтвердження перед входом у git worktree поза директорією `.claude/worktrees/` проекту
- Фонові агенти тепер оновлюються до нової версії у фоні одразу після оновлення Claude Code, замість повільного stale-session upgrade при attach

## Виправлення

- Виправлено expired login що викликав збій кожної моделі з хибним повідомленням «There's an issue with the selected model» замість пропонування `/login`
- Виправлено `claude --resume` та `--continue` що не реагували на ввід з клавіатури під час запуску
- Виправлено MCP сервери (через `--mcp-config` або `.mcp.json`) що ігнорували per-server `request_timeout_ms`, через що довготривалі MCP tool calls переривались за 60s default timeout у fresh sessions
- Виправлено `CLAUDE_CODE_EXTRA_BODY` що мовчки ігнорувався `claude agents` / `--bg` background workers; shell-exported override тепер слідує за dispatching session
- Виправлено OAuth MCP сервери що вимагали повторну автентифікацію після одного невдалого token refresh
- Виправлено `--permission-prompt-tool` що вказував на MCP сервер та завершувався помилкою «MCP tool not found» на cold start до завершення підключення сервера
- Виправлено `/model` picker що показував ціну іншої моделі ніж у рядку; прибрано first-party list prices для providers що їх не виставляють
- Виправлено server-provided model rows що зміщувались у `/model` picker коли entitlement або allowlist обмеження прибирало рядок відносно якого вони позиціонувались
- Виправлено desktop sessions що застрягали у стані «running» після slash command надісланої під час turn
- Виправлено ігнорування вводу з клавіатури у agents view коли setup prompt з'являвся перед bare `claude --resume` на Windows
- Виправлено `claude rm` що залишав видалений job у daemon roster, через що рядок знову з'являвся у `claude agents`
- Виправлено `/remote-control` що показував «Unknown command» без входу — тепер пояснює як увійти
- Виправлено ліву стрілку що не виходила назад з phase або agent у workflow detail view
- Виправлено `/status` що виводив одне й те саме broken-install попередження двічі
- Виправлено хибні поради «disused plugin» та викривлену disuse telemetry для LSP плагінів

- Виправлено fullscreen jump-to-bottom pill що пропонував Ctrl+End на macOS, не показував rebound chords та переносив через транскрипт
