# Реліз 2.1.203 — 2026-07-08

## Нові можливості
- Попередження про спливання логіну (переавтентифікація до переривання background sessions)
- Сірий значок ⏸ у footer в manual permission mode
- MCP `roots/list` з додатковими робочими директоріями + `notifications/roots/list_changed`
- VSCode toggle "Enable Remote Control for all sessions"

## Виправлення
- macOS stall 15–20s при background agents (хибне low-memory detection, регресія з 2.1.196)
- Background sessions permanent unresponsive при stale token daemon
- Memory/CPU regression (context-usage indicator переаналізував весь транскрипт)
- Daemon auto-upgrade мовчки вбивав running sessions
- Background agents stale PATH на Windows
- Background/agent-view sessions втрачали shell-exported `ANTHROPIC_BASE_URL`
- Bash "argument list too long" з багатьма git worktrees
- Worktree subagents виконували команди в батьківському checkout
- Worktree відхиляв nested repositories
- Background agents crash-looping при видаленій робочій директорії
- `TaskStop`/`TaskOutput` не знаходили cross-agent background agents
- `claude agents` composer відкидав повідомлення при недоступній slash команді
- Agent list crash при дублікатному відкритті сесії
- "Needs input" після відповіді на питання
- Startup failures показували лише "exit_with_message"
- `effortLevel` changes ігнорувалися в background sessions
- Attached sessions ігнорували `CLAUDE_CODE_DISABLE_MOUSE` / `CLAUDE_CODE_DISABLE_MOUSE_CLICKS`
- `/exit` хибно попереджав про running background agents
- `WorktreeCreate` hook блокував редагування з non-git директорій
- `@` picker не показував git worktrees
- `/clear` замінював background task output на порожній файл на Windows
- Content jumping при скролі через довгу історію
- Terminal flickering в bash mode з shell-history підказками
- Escape codes `^[[I` / `^[[O` при reattach
- LSP-only плагіни хибно позначалися як непридатні
- `claude agents` мовчки зупиняв running subagents при поверненні

## Покращення
- Streaming responsiveness: live-preview більше не перемальовує весь екран
- Subagents менш схильні повністю делегувати завдання іншому subagent
- Бінарний розмір -7MB, startup memory -7MB (lazy loading)

## Важливі зміни
- Left arrow більше не закриває background tasks/diff/workflow views — використовуйте Esc
- Startup warnings ("claude command missing or broken") перенесено в `/doctor` та `/status`
- Порожній `claude agents` тепер завжди показує організовані секції
- Прибрано redundant navigation hint з `claude agents` footer
