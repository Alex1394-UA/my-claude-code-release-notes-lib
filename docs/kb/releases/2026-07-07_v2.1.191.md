# Реліз 2.1.191 — 2026-07-07

## Нові можливості
- `/rewind` тепер підтримує відновлення розмови з стану до виконання `/clear` (категорія: cli)
- Vim mode: пошук історії в NORMAL mode через `/` тепер підказує як досягтися slash-команд (категорія: keybindings)

## Виправлення
- Виправлено стрибок позиції скролу вниз під час читання раніше output під час стрімінгової відповіді (категорія: core)
- Виправлено фонових агентів що "воскресали" після зупинки — зупинка з tasks panel тепер остаточна (категорія: skills-agents)
- Виправлено `/voice` що показував generic "not available" замість пояснення обмеження політики (категорія: core)
- Виправлено `/login` URL що обрізався при переносі через рядки в Windows Terminal (категорія: cli, windows)
- Виправлено Cmd+click що не відкривав посилання в fullscreen mode в Ghostty через ssh/tmux (категорія: core)
- Виправлено `claude agents` що надсилав вбудовані slash команди як prompt text до background sessions (категорія: cli)
- Виправлено `claude agents` job rows що показували повні шляхи замість `[Image #N]` для вставлених зображень (категорія: cli)
- Виправлено хуки з comma-separated matchers (напр. `"Bash,PowerShell"`) що мовчазно ніколи не спрацьовували (категорія: hooks)
- Виправлено `/permissions` Recently-denied tab: схвалення відхилення тепер зберігається при закритті (категорія: settings)
- Виправлено агент-панель що стрибала на один ряд при скролі списку за межу overflow (категорія: skills-agents)
- Виправлено overflow welcome splash art в стандартному macOS Terminal (80×24) (категорія: core)
- Виправлено `forceRemoteSettingsRefresh` — тепер працює при встановці через MDM або file policy; fetch відправляє `Cache-Control: no-cache` (категорія: settings)

## Покращення
- Зменшено використання CPU на ~37% під час стрімінгових відповідей шляхом коалесценції текстових оновлень до 100ms (категорія: core)
- Виправлено зростання пам'яті в довгих сесіях від кешу термінального output (категорія: core)
- MCP capability discovery (`tools/list`, `prompts/list`, `resources/list`) тепер повторює при transient network помилках з коротким backoff (категорія: mcp)
- MCP OAuth discovery та token requests тепер повторюють один раз при transient network помилках; headless середовища пропускають browser popup (категорія: mcp)
- MCP HTTP 404 помилки тепер показують URL та вказують на MCP конфіг (категорія: mcp)
- Sandbox network permission dialog: дозволи "Yes" тепер запам'ятовуються на решту сесії замість повторного промпту (категорія: settings)
