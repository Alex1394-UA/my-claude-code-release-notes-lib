# Реліз 2.1.176 — 2026-06-13

## Нові можливості

- Заголовки сесій тепер генеруються мовою розмови (новий параметр `language` дозволяє зафіксувати конкретну мову)
- Новий setting `footerLinksRegexes` для regex-відповідностей link badges в footer row (конфігурується через user або managed settings)
- Покращене кешування облікових даних Bedrock: `awsCredentialExport` кешується до `Expiration` замість фіксованої 1 години

## Виправлення

- `availableModels` enforcement: alias model picks більше не перенаправляються до заблокованої моделі через `ANTHROPIC_DEFAULT_*_MODEL`; `/fast` відмовляється перемикати для моделей поза allowlist
- Auto mode на Fable 5 для організацій без Opus 4.8 — класифікатор тепер відступає до найкращої доступної Opus моделі
- Hook `if` умови для Read/Edit/Write tool paths: патерни як `Edit(src/**)`, `Read(~/.ssh/**)`, `Read(.env)` тепер збігаються коректно
- Linux sandbox не стартував коли `.claude/settings.json` є symlink з абсолютною ціллю
- `/copy` та mouse-selection copy не досягали system clipboard всередині tmux over SSH; tmux paste buffer не завантажувався на версіях старіших за 3.2
- Remote Control: підключення з web/mobile мовчки перемикало модель сесії
- Remote Control: notifications disconnect показували bare numeric code замість людського опису; connection failures більше не додають дубльований рядок
- Remote Control: sessions не відключались при вході в інший акаунт
- `/cd` та worktree moves залишали сесію з повідомленням git branch попередньої директорії
- `claude agents`: натискання ← в одному вікні відокремлювало інші вікна підключені до тієї ж сесії
- Backgrounded sessions показували "Working" назавжди коли `/bg` mid-turn не мав що продовжувати
- Background agent пошук по PR URL: PRs створені під час scheduled wakeups тепер з'являються в пошуку
- Agents view input не показував текстовий курсор на Windows
- `claude --bg -cn <name>` не насідав ім'я сесії
- Background sessions нейтралізують Windows network paths в persisted state перед respawn
- Background-session respawn відхиляв malformed resume IDs з пошкоджених state files
- Windows background-service daemon не стартував коли `~/.claude/daemon` має ReadOnly атрибут
- Cloud sessions failing з "Could not resolve authentication method" при тривалому простої
- Background sessions тепер показують чіткішу підказку при auto-update version skew; `claude daemon status` пояснює поведінку
