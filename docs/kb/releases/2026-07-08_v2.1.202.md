# Реліз 2.1.202 — 2026-07-08

## Нові можливості
- `dynamicWorkflowSize` setting в `/config` для керування розміром dynamic workflows (small/medium/large)
- `workflow.run_id` та `workflow.name` OpenTelemetry атрибути для відновлення діяльності workflow-запуску з OTel-даних

## Виправлення
- Краш inline Ctrl+R history search при прийнятті/скасуванні під час сканування
- `/rename` на background sessions відкатувався при рестарті job
- Transient mTLS handshake помилки під час ротації клієнтського сертифікату
- Команди з Remote Control (mobile/web) failing з "Unknown command"
- Зображення та файли з Remote Control без caption мовчки відкидались
- Sign-in URL від `claude auth login` не надійно клікався через SSH
- `claude agents` opening chat crash з worker crash/respawn loop
- Workflow scripts з unicode quote escapes пошкоджувались перед парсингом
- Voice dictation unbounded loop при невдалому записі
- `/remote-control` sessions показували неправильний permission mode
- Resume by name або resume picker займали хвилини з багатьма git worktrees
- Installer/updater download failing при transient connection drops
- Повторний виклик вже завантаженого skill додавав дублікат інструкцій
- Покращено error messages MCP (`url` без `type`)
