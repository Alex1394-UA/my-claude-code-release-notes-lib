# Реліз 2.1.160 — 2026-06-06

## Нові можливості

- Промпт перед записом в shell startup files (`.zshenv`, `.zlogin`, `.bash_login`) та `~/.config/git/`
- `acceptEdits` mode промптить перед записом build-tool config files (`.npmrc`, `.yarnrc*`, `.bunfig.toml`, `.bazelrc`, `.pre-commit-config.yaml`, `.devcontainer/`)
- `grep`/`egrep`/`fgrep` single-file команди задовольняють read-before-edit перевірку
- Dynamic-workflow ключове слово перейменовано з `workflow` на `ultracode`
- Видалено `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE` (now no-op)
- Видалено пропозицію встановлення JetBrains plugin при старті

## Виправлення

- Copy-on-select не писав в Windows clipboard на WSL — тепер використовує PowerShell interop замість OSC 52
- Відновлення завершеної сесії з `claude agents` втрачало chat history та повторно запускало промпт
- Background sessions повторно підключались після overnight retire з втраченою розмовою
- `claude --bg` періодично failing з "socket missing" при cold-start
- Background agents показувались під Completed в agents list
- `claude agents` зависав на кілька секунд через auto-updater re-check при кожному exit
- Esc, arrow keys, typing unresponsive на Windows при background sessions під високим CPU
- Background agents надсилали sync-output markers на несумісні термінали (Apple Terminal, tmux)
- Mouse wheel скролив prompt history замість транскрипту після відкриття сесії з agents list
- CJK IME composition з'являвся в bottom-left замість біля input caret
- Valid `file:///C:/...` links переписувались в broken path на Windows
- Voice mode не підключався з non-ASCII в project directory або branch name
- Auto mode unavailability message хибно звинувачував модель на 3p providers
- `/effort ultracode` хибно звинувачував dynamic workflows setting
- Model-not-found errors пропонували `--model` на SDK/hosts де CLI flag не застосовується
- Past replies зникали зі scrollback при відновленні brief mode сесії з вимкненим brief mode
- Vim mode `p` paste вставляв на рядок нижче замість біля курсору при `v$` yank
- Directory background session не могла бути видалена після `claude rm` поки daemon не вийшов

## Покращення

- Покращено продуктивність відкриття неактивних background agent sessions
- Покращено auto mode класифікатор latency — зменшено reasoning на routine actions
- Покращено background session teardown — SIGTERM перед SIGKILL для cleanup handlers
