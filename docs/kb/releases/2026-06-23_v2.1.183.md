# Реліз 2.1.183 — 2026-06-23

## Нові можливості

- **Auto mode безпека: блокування деструктивних команд** — `git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop` блокуються коли користувач не просив відкидати локальні зміни; `git commit --amend` блокується якщо коміт не від агента цієї сесії; `terraform destroy`/`pulumi destroy`/`cdk destroy` блокуються без явного запиту на конкретний стек
- **Попередження про застарілу модель** — попередження на stderr коли модель застаріла або автоматично оновлена; працює в `-p` та для моделей з agent frontmatter
- **`attribution.sessionUrl`** — новий setting для прибрання посилання на claude.ai сесію з комітів та PR в web та Remote Control сесіях
- **`/config --help`** — перелік усіх доступних скорочень для `/config key=value`
- **Змінена поведінка `/config` toggle** — Enter та Space обидва змінюють вибране налаштування, Esc зберігає та закриває замість скасування
