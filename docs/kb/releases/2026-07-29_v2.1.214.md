# Реліз 2.1.214 — 2026-07-29

> Версія 2.1.213 відсутня — після 2.1.212 одразу йде 2.1.214.

## Нові можливості

- `EndConversation` — новий інструмент: Claude може завершувати сесії з вкрай абузивними користувачами або jailbreak-спробами, як на claude.ai з 2025 (категорія: core)
- `CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH` — нова змінна: ліміт 60 КБ обрізання content-атрибутів OpenTelemetry (категорія: env-vars)
- `message.uuid` / `client_request_id` / `tool_source` — нові OTel-атрибути для message-level correlation та tool provenance (категорія: env-vars)
- `subagentStatusLine` reasoning effort — кастомні agent rows тепер рендерять модель та effort (категорія: skills-agents)
- Progress heartbeat — періодичний пульс поступу для довготривалих tool calls (категорія: core)
- ISO `modified` timestamp у frontmatter файлів пам'яті (категорія: core)
- Промпти дозволів для `docker` з daemon-redirect прапорцями (`--url`, `--connection`, `--identity`, Podman remote mode) (категорія: settings)

## Важливі зміни

- Односегментні `dir/**` умови `if:` хаків збігаються лише з `<cwd>/dir`; `deny`/`ask` зберігають any-depth збіг (hooks)
- `file` з `-m`/`--magic-file` або `-f`/`--files-from` тепер вимагають дозвіл (settings)
- Keep-alive pooling вимикається після stale-connection помилки (env-vars)
- SessionStart хаки повідомляють source `fork` для fork-сесій (hooks)
- Покращено помилку workspace-trust `claude rc` у home directory (cli)
