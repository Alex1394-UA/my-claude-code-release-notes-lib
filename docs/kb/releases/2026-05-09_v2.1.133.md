# Реліз 2.1.133 — 2026-05-09

## Нові можливості
- `worktree.baseRef` setting (`fresh` | `head`) — вибір базової гілки для worktrees (категорія: settings)
- `sandbox.bwrapPath` / `sandbox.socatPath` — managed settings для кастомних шляхів bubblewrap/socat на Linux/WSL (категорія: settings)
- `parentSettingsBehavior` admin-tier key — дозволяє SDK managed settings брати участь у policy merge (категорія: settings, sdk)
- Хуки отримують `effort.level` JSON input та `$CLAUDE_EFFORT` env var (категорія: hooks, env-vars)
- Покращено focus mode behavior (категорія: core)

## Виправлення
- Звільнення warm-spare background workers під memory pressure (категорія: core)
- Паралельні сесії 401 після refresh-token race (категорія: core)
- `Edit`/`Write` allow правила для drive root (`C:\`) та POSIX `/` (категорія: settings, windows)
- Unhandled rejection `ECOMPROMISED` при file lock compromise (категорія: core)
- Spurious "Error compacting conversation" при Esc під compaction (категорія: core, keybindings)
- `HTTP(S)_PROXY` / `NO_PROXY` / mTLS для MCP OAuth flow (категорія: mcp)
- Read/Write/Edit на mapped network drives через `--add-dir` (категорія: windows)
- Remote Control stop/interrupt не fully cancel CLI session (категорія: sdk)
- `/effort` в одній сесії змінював effort level інших (категорія: core)
- Subagents не discovering skills через Skill tool (категорія: skills-agents)
- `claudeProcessWrapper` "Unsupported platform" (категорія: vscode-ide)

## Важливі зміни
- `worktree.baseRef` за замовч. `fresh` — змінює `EnterWorktree` base назад на `origin/<default>` (з 2.1.128 було local HEAD)
- `claude --help` тепер lists `--remote-control`
