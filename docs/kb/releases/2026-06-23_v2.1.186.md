# Реліз 2.1.186 — 2026-06-23

## Нові можливості

- **`claude mcp login <name>` / `claude mcp logout <name>`** — автентифікація MCP серверів з CLI без інтерактивного меню; `--no-browser` для SSH
- **`teammateMode: "iterm2"`** — setting для tmux teammate panes через iTerm2
- **`respondToBashCommands`** — `!` bash команди тепер автоматично викликають відповідь Claude; `false` для попередньої поведінки
- **`/plugin` Installed "Skills" секція** — перегляд навичок з плагінів на вкладці Installed
- **`/login` AWS refresh credentials** — новий запис для оновлення AWS облікових даних
- **`CLAUDE_CODE_MAX_RETRIES` cap 15** — обмеження максимум 15; для unattended сесій — `CLAUDE_CODE_RETRY_WATCHDOG`
