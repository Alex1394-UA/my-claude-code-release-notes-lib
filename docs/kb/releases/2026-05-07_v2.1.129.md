# Реліз 2.1.129 — 2026-05-07

## Нові можливості
- `--plugin-url <url>` для завантаження plugin `.zip` з URL (cli, plugins)
- `CLAUDE_CODE_FORCE_SYNC_OUTPUT=1` для synchronized output (env-vars)
- `CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE` для auto-upgrade на Homebrew/WinGet (env-vars)
- Plugin manifests: `themes`/`monitors` під `"experimental"` (plugins)
- `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` opt-in для gateway model discovery (env-vars)
- Ctrl+R history picker: пошук по всіх проектах за замовчуванням, Ctrl+S для звуження (core)
- Third-party deployments: spinner tips без first-party посилань (core)
- `skillOverrides` setting для контролю видимості skills (settings)
- `claude_code.pull_request.count` OTel metric включає MCP tools (sdk)
