# Реліз 2.1.205 — 2026-07-09

## Нові можливості

- Auto mode: нове правило що блокує втручання у файли транскриптів сесії
- Auto mode: запит підтвердження перед `rm -rf` для змінної що не може бути розпізнана з контексту
- `/doctor` перетворено на повну діагностику з можливістю виправлення проблем; `/checkup` — аліас
- Імена "Claude Browser" та "Claude Preview" зарезервовано для MCP серверів — користувацькі сервери не можуть бути зареєстровані під цими іменами
- Agent view: рядки тепер показують кольорове слово стану та згенерований класифікатором заголовок замість сирих викликів інструментів; peek відкривається з повним статусом
- Agent view: сесії що редагують, мержать, коментують або пушать існуючий PR тепер показують посилання на нього в `claude agents`
- Сповіщення фонових задач тепер явно вказують що людського вводу не було, запобігаючи діям на підставі вигаданих підтверджень

## Виправлення

- Виправлено `--json-schema` що мовчки видавав неструктурований вивід при невалідній схемі, та відхилення схем з ключовим словом `format`
- Виправлено втрату повідомлення надісланого під час роботи Claude коли turn завершувався на ліміті `--max-turns`
- Виправлено видалення worktree на Windows що видаляло файли поза межами worktree коли всередині існував NTFS junction або directory symlink
- Виправлено фонові агенти що залишалися в статусі "failed" або "completed" після відновлення через `SendMessage`
- Виправлено фонові задачі що переключались з "needs input" назад на "working" коли turn агента не містив читабельного тексту
- Виправлено `claude attach` що видавав помилку коли фоновий агент перезапускався через оновлення
- Виправлено зв'язок сесії з PR що не створювався для PR створеного через Bash з виводом понад 30K символів
- Виправлено `claude mcp add-from-claude-desktop` що зависав при імені сервера з неприпустимими символами
- Виправлено плагінний LSP server що не стартував та блокував інший валідний LSP server від іншого плагіна
- Виправлено краш на Windows коли директорія з якої запущено Claude видаляється, блокується або відмонтується
- Виправлено краш коли file watcher закривався під час активного сканування директорії
- Виправлено project verify skills що перезаписувалися при кожній сесії замість лише при зміні задокументованої команди
- Виправлено agent view що рендерив на один рядок вище та обрізав заголовок
- Виправлено stale статус "Running" фонових задач у web та mobile Remote Control панелях
- Виправлено local-agent сесії в Cowork VM-mode що не стартували з "Not logged in" на CLI 2.1.203+
