# Реліз 2.1.200 — 2026-07-08

## Важливі зміни
- Дефолтний permission mode змінено на "Manual" у CLI, `--help`, VS Code та JetBrains; `--permission-mode manual` та `"defaultMode": "manual"` приймаються поруч із `default`
- `AskUserQuestion` діалоги більше не автоматично продовжуються; idle timeout можна увімкнути через `/config`

## Виправлення
- Виправлено краш при старті коли `disabledMcpServers` або `enabledMcpServers` в `.claude.json` встановлено не як масив
- Виправлено зупинку background sessions під час сну/пробудження або повторного відкриття застарілої сесії
- Виправлено повторний запуск відміненого повороту (Esc) після перезапуску застарілої сесії
- Виправлено background agents що ніколи не запускались знову після крашу що залишив stale `daemon.lock` з PID повторно використаним ОС
- Виправлено handover daemon так що старіший білд після перевстановлення не може перехопити daemon
- Виправлено кілька проблем background-agent roster: transient corruption orphan cleanup, старіші binaries не зберігали поля новіших версій, socket auth tokens втрачались при рестарті
- Виправлено субагентів обірваних rate limit до генерації тексту — повертають помилку замість порожнього результату
- Виправлено потрапляння control bytes від background-agent output в термінал в agent view
- Виправлено `claude agents --plugin-dir <dir>` що не показував agents та skills плагіна коли прапорець розташований після `agents`
- Виправлено project-scoped plugins що не завантажувались з git worktrees того ж репозиторію
- Виправлено `/mcp` server list що не відстежував фокус для screen readers та magnifiers
- Виправлено оманливе повідомлення "Voice connection failed" коли recording не містить аудіо
- Виправлено мерехтіння рендерингу під tmux 3.4+ увімкненням synchronized terminal output

## Покращення
- Покращено screen-reader output: декоративні символи приховані, транскрипт-символи читаються як короткі мітки, вкладені таблиці як `Header: value.`
- Покращено скрипт встановлення: пояснює коли installation зупинено через нестачу пам'яті

## Нові можливості
- `--permission-mode manual` як синонім `--permission-mode default` (Manual тепер є дефолтним режимом)
