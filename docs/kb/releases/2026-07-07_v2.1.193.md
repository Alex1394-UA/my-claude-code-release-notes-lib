# Реліз 2.1.193 — 2026-07-07

## Нові можливості
- `autoMode.classifyAllShell` setting для маршрутизації всіх Bash/PowerShell команд через auto-mode класифікатор
- `OTEL_LOG_ASSISTANT_RESPONSES` env var для керування логуванням тексту відповіді моделі через OTEL
- `claude_code.assistant_response` новий OTEL log event з текстом відповіді моделі
- `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP` env var для вимкнення memory-pressure reaping фонових shell команд
- Autocomplete шляхів файлів у bash mode (`!`)
- Стартове повідомлення з підказкою `/mcp` коли MCP сервери потребують автентифікації
- Автоматичне звільнення простоючих фонових shell команд під memory pressure

## Виправлення
- `/model` та інші UI-елементи показували застарілий/порожній стан одразу після `/login`
- Backgrounding (←←) spuriously скасовував з повідомленням "N background tasks would be abandoned" коли всі задачі переносяться
- Pinned background агенти повторно отримували "Continue from where you left off" після автооновлення
- Backgrounding основного повороту створював фіктивний "general-purpose (resumed)" субагент
- Агент-панель ховала sibling-агентів при перегляді субагента
- `headersHelper` тепер автоматично повторно запускається при 401/403 від tool call
- Plugin marketplace `renames` maps тепер слідуються автоматично
- Покращено повідомлення `/add-dir` коли директорія вже є робочою

## Важливі зміни
- `OTEL_LOG_ASSISTANT_RESPONSES` при нестандартному значенні слідує за `OTEL_LOG_USER_PROMPTS`, що означає деплої що вже логують промпти почнуть отримувати текст відповіді при оновленні — встановіть `0` для вимкнення
