# Реліз 2.1.199 — 2026-07-08

## Нові можливості
- Stacked slash-skill invocations: `/skill-a /skill-b do XYZ` завантажує всі leading skills (до 5), не лише перший

## Виправлення
- SSL certificate errors (TLS-inspecting proxies, missing `NODE_EXTRA_CA_CERTS`, expired certs) тепер fail негайно з підказкою замість спалювання retries
- Streaming відповіді що відкидались при mid-stream overloaded/server error — partial response тепер зберігається
- Субагенти обірвані rate limit або server error тепер повертають часткову роботу батьківському агенту
- Субагенти звітували API помилки як успішні результати — помилка тепер передається батьківському агенту
- Background-agent daemon на Linux вбивав себе кожні ~50с після unclean shutdown з пошкодженим worker record
- Background agents не могли холодно стартувати через SSH на macOS (регресія з 2.1.196)
- `claude stop` мовчки скасовувався при змаганні з respawn background-агента
- Індикатори прогресу background job зупинялись на хвилини під час довгих команд
- Фонові сесії на машинах з нестачею пам'яті показували generic помилку — тепер вказують на low memory
- Remote sessions кратко перемикались між Working та Idle в агент-панелі
- Idle субагенти згортаються в expandable summary рядок замість зникнення з панелі
- `/model` або `/fast` під час перегляду субагента мовчки відкривав model picker лідера
- `SessionStart`, `Setup`, `SubagentStart` хуки мовчки приховували stderr при exit code 2
- `claude --dangerously-skip-permissions daemon <subcommand>` трактувався як chat prompt
- `SendMessage` мовчки маршрутизував на неправильного агента при повторному використанні імені
- Відкриття/відновлення сесії без нових повідомлень непотрібно зростало транскрипт
- Backgrounding сесії через `←` або `/background` втрачував `/color`
- Скидання пошкодженого config файлу з startup recovery dialog тепер резервно копіює файл
- Claude in Chrome повторно відкривав сторінку reconnect при різних builds/config directories
- План-режим не запитував підтвердження для state-changing browser tool calls
- Transient server rate-limit 429s автоматично повторюються з backoff для підписників
- `CLAUDE_CODE_RETRY_WATCHDOG` підвищує дефолтні retries до 300 та знімає cap 15 на `CLAUDE_CODE_MAX_RETRIES`
- `claude agents` session rows тепер показують PR links як `#N`
