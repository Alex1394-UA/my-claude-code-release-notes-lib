# Реліз 2.1.163 — 2026-06-06

## Нові можливості

- `requiredMinimumVersion` / `requiredMaximumVersion` managed settings — Claude Code відмовляється стартувати якщо версія поза діапазоном
- `/plugin list` з фільтрами `--enabled`/`--disabled`
- `/btw` скорочення `c` для копіювання raw markdown в clipboard
- Stop/SubagentStop хуки можуть повертати `hookSpecificOutput.additionalContext` для зворотного зв'язку без hook error
- Skills `\$` escape syntax для літерального `$` перед цифрою
- stdio MCP сервери отримують `CLAUDE_CODE_SESSION_ID` при `--resume`

## Виправлення

- `claude -p` зависав назавжди коли backgrounded команда ніколи не завершується
- `claude -p` failing з "ANTHROPIC_API_KEY required" на Bedrock/Vertex/Foundry при `CI=true`
- Bash `$TMPDIR` override regression (bazel/EDR-protected Go workflows)
- Bash EEXIST на session-env directory з read-only атрибутом або OneDrive [Win]
- Org-managed permission rules не застосовувались коли fetch завершувався під час startup
- Background sessions втрачали running tasks при reattach після оновлення
- Terminal misalignment та hang при виході з agent view через Esc
- Stop chip не очищався коли процес вже завершився
- Keyboard input назавжди unresponsive після paste з втраченим кінцевим маркером
- Hook `if: "Bash(...)"` спрацьовував на кожну команду з `$()` або `$VAR`
- Deny правила на домашніх шляхах не блокували Bash через `$HOME`
- Сторонній "(no content)" рядок після закриття панельних діалогів

## Покращення

- Background agent sessions оновлюються у фоні без cold restart
- Покращено описи вбудованих команд та навичок в `/` menu
- Підказка перемикання підписки в startup announcement slot
- `claude agents` dispatch з state-grouped view стартує в correct directory
