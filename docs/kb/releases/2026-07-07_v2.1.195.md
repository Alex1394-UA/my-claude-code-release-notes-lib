# Реліз 2.1.195 — 2026-07-07

## Нові можливості

- `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` — нова змінна середовища для вимкнення mouse click/drag/hover у fullscreen mode з збереженням wheel scroll
- Remote session startup provisioning checklist — покращений старт remote sessions з checklist поки контейнер запускається

## Виправлення

- Hook matchers з дефісованими ідентифікаторами (напр. `code-reviewer`, `mcp__brave-search`) більше не substring-matching — тепер точний збіг
- Voice dictation на macOS: виправлено записування тиші в довгих сесіях після зміни стандартного пристрою вводу
- Voice dictation auto-submit: виправлено для мов написаних без пробілів (японська, китайська, тайська)
- External plugins увімкнені лише через project `.claude/settings.json` більше не вимагають підтвердження install при кожному завантаженні
- `/plugin` Enable/Disable: виправлено коли `plugin.json` `name` відрізняється від marketplace entry name
- Background jobs: виправлено зникнення з `claude agents` або втрату даних коли записані новішою версією
- Crashed background task: виправлено пустий екран до 5 секунд при відновленні
- Background agent daemons: виправлено unreachable стан коли control socket не стартував
- Voice mode на Linux: розрізнення "немає мікрофона" від "SoX не встановлено"
- `claude agents` completed list: заповнює вертикальний простір; header стискається на коротких терміналах

## Важливі зміни

- Hook matchers тепер exact-match для дефісованих ідентифікаторів; використовуйте glob-патерн (напр. `mcp__brave-search__.*`) для wildcard matching
