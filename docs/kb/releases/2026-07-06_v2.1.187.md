# Реліз 2.1.187 — 2026-07-06

## Нові можливості
- `sandbox.credentials` — блокування sandboxed команд від читання credential файлів та секретних змінних середовища
- Org-configured model restrictions — обмеження моделей від організації в model picker, `--model`, `/model`, `ANTHROPIC_MODEL`
- Mouse click support для select menus в fullscreen mode
- `CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT` — таймаут для remote MCP tool calls без відповіді (за замовч. 5 хв)
- `/btw` ←/→ arrow навігація для перегляду попередніх відповідей
- `/install-github-app` — GitHub Actions workflow setup тепер опціональний
- `/plugin` — показ непотрібних плагінів для очищення

## Виправлення
- `--resume` failing з "No conversation found" коли оригінальний `-p` запуск не producував model turns
- `--json-schema` та workflow `agent({schema})` structured output: модель більше не може нескінченно re-call `StructuredOutput`
- Remote MCP tool calls що зависають 5 хвилин — тепер abort з помилкою
- Claude Code Remote sessions startup на ~2.7с довше після agent proxy CA system-trust install
- Korean/CJK paste mojibake в терміналах з per-byte extended-key events
- `/update` через Remote Control що зависав при startup trust dialog
- Background jobs в agents view що застрягали в "working" назавжди
- Channel connections dropping після навігації до agents view та назад
- Agent stop notifications: некоректна атрибуція хто зупинив агента
- Subagent depth tracking: відновлені субагенти відновлюють spawn depth, forked рахуються до depth cap
- Leaked agent worktree registrations: locked `.git/worktrees/` entries автоматично очищаються
- Cmd+click не відкривав URL в fullscreen mode в Ghostty на macOS
- `claude --help` не показував `--bg`/`--background` прапорці
- Esc, Ctrl-C, Ctrl-D не працювали під час `/share` завантаження
- [VSCode] Extension ставав unresponsive при відновленні великої сесії
