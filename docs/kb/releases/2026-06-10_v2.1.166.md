## Нові можливості
- `fallbackModel` setting — до трьох fallback-моделей послідовно при перевантаженні (категорія: settings)
- `--fallback-model` — працює в інтерактивних сесіях (раніше лише `-p`) (категорія: cli)
- Glob patterns у deny rules — `"*"` забороняє всі інструменти (категорія: settings)
- Cross-session messaging hardened — relay-повідомлення без user authority (категорія: core)
- `MAX_THINKING_TOKENS=0` / `--thinking disabled` — вимикає thinking на моделях за замовчуванням (категорія: core)
- API error fallback retry — один retry на fallback-моделі при non-retryable помилці (категорія: core)
- `claude update` оголошує цільову версію перед завантаженням (категорія: cli)
- `claude agents` URL фільтр — введення URL фільтрує до сесії з цим URL (категорія: cli)
