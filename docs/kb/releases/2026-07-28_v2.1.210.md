# Реліз 2.1.210 — 2026-07-28

## Нові можливості

- **Лічильник тривалості інструменту** — згорнутий рядок підсумку tool-call показує лічильник часу що оновлюється наживо, щоб довгі виклики visibly тікали замість того щоб виглядати завислими
- **Startup-попередження для permission rules** — `Write(path)`, `NotebookEdit(path)` та `Glob(path)` тепер викликають попередження при запуску; використовуйте натомість `Edit(path)` або `Read(path)`
- **Agents footer — лічильник очікуючих** — підказка в agents view показує скільки background-агентів чекають на ваш ввід, з коротким кольоровим акцентом при зміні кількості
- **Agent view — позначка активної сесії** — сесія з якої натиснули ← лишається візуально позначеною навіть після переміщення виділення мишею або стрілками
- **Screen reader — оголошення permission mode** — screen reader mode голосно оголошує зміни permission mode під час перемикання режимів клавішею Shift+Tab

## Виправлення

- `isolation: 'worktree'` субагенти більше не можуть виконати git-мутуючі команди проти основного checkout репозиторію замість власного ізольованого worktree
- Ключове слово `ultracode` opt-in більше не спрацьовує на не-людському вводі (webhook payloads, ретрансльовані PR коментарі)
- Фрагмент тексту що рендерився більше не витікав у crash-телеметрію коли UI-компонент повертав контент поза styled text-елементом
- Paste-маркери більше не витікають у зовнішні редактори відкриті з Claude Code (з'являлись як зайві символи È/É навколо вставленого тексту)
- `claude attach` більше не падає з "job not found" або "agent is still starting" під час переходів сесії — attach чекає поки daemon стабілізується, а resize терміналу під час повільного attach застосовується після завершення
- Краш сесії коли рендерер результату інструменту повертав числове значення bigint або звичайний текст замість UI-елемента
- Таймаут hook-callback більше не повідомляється моделі як відмова користувача — це зупиняло unattended сесії в очікуванні
- Claude більше не припускав що `cd` набув чинності після переміщення команди у фон — результат інструменту тепер явно повідомляє що робочий каталог не змінився
- Plugin-provided MCP сервери більше не знищуються під час повторної синхронізації MCP посеред сесії
- Схвалення плану без редагувань більше не позначається "(edited by user)" і не перезаписує файл плану застарілим снапшотом
- `/doctor` більше не пропускає пропозицію auto-mode default на Bedrock, Vertex та Foundry, де auto mode більше не потребує opt-in
- Content-режим Grep більше не повідомляє "No matches found" при пагінації за межі результатів
- Невідповідні позиційні плейсхолдери `$1`/`$2` у skills та командах більше не вилучаються мовчки — зберігаються дослівно
- Запис plugin cache більше не лишає temp-файли при збоях і не падає на rename заблокованого файлу на Windows та мережевих ФС
- Зациклення крашів background workers коли клієнт скидав з'єднання з background-сервісом
- `claude agents --effort ultracode` більше не скидає значення мовчки — воно доходить до розгорнутих сесій
- Натискання ← для відкриття agents view більше не скидає task tracker при поверненні в сесію
- Agents dashboard більше не утримує вставлені зображення з покинутих чернеток відповідей після видалення сесії
- Вбиті background-сесії більше не залишають постійний `git worktree lock` — періодичний sweep звільняє lock'и чий процес-власник зник
- SDK MCP сервери зареєстровані через `initialize` control request більше не чекають наступного ходу для початку з'єднання
- Повернення в agents view з сесії більше не лишає накладні ghost-фрейми з `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1`
- Пізно з'явлені `.claude/*` symlink'и тепер звіряються зі списком sandbox deny-write
- Записи в пам'ять що перевищують ліміт читання індексу MEMORY.md повертають явну помилку замість мовчазного обрізання

## Покращення

- Посилено Agent tool проти непрямої prompt injection через контент який прочитав субагент
- Покращено повідомлення Bash/PowerShell інструменту при таймауті з авто-переходом у фон — модель розрізняє зависання від явного background-запиту
- Auto mode: permission classifier типово використовує Sonnet 5 для зовнішніх сесій, перевіряється на першому запиті та фіксується для сесії
- Покращено валідацію кольорів графіків у bundled dataviz skill: перцептивна OKLab-різниця та перекалібровані пороги дальтонізму
- Fable тимчасово показується як недоступний в advisor picker поки усувається server-side проблема що викликала збій Fable advisor
