# Реліз 2.1.211 — 2026-07-28

## Нові можливості

- `--forward-subagent-text` — новий CLI прапорець, що включає текст та роздуми субагентів у stream-json вивід (категорія: cli)
- `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` — нова змінна середовища з тим самим призначенням (категорія: env-vars)
- Цілочислові змінні середовища (таймаути, бюджети токенів, лічильники повторів) тепер приймають наукову нотацію та роздільники цифр на кшталт `1e6` і `64_000` (категорія: env-vars)
- `save_to_disk` у діях скриншота Claude in Chrome тепер записує зображення на диск і повертає шлях (категорія: vscode-ide)

## Виправлення

- PreToolUse `ask` хака більше не перевизначається auto mode для несендбоксованого Bash (hooks)
- Попередній перегляд дозволів, переданих до chat-каналів, нейтралізує символи bidirectional-override, нульової ширини та подібні до лапок (settings)
- Паралельні сесії більше не виходять одночасно після пробудження зі сну при спільному сховищі облікових даних (core)
- Plugin MCP-сервери перепідключаються після пробудження простоюючої веб-сесії (mcp)
- Vertex та Bedrock більше не пробують типову Opus-модель при явно налаштованій моделі (core)
- Субагенти зі явним model override більше не відкочуються до моделі батька при поновленні (skills-agents)
- Вкладені `.claude/rules/*.md` не завантажуються, коли джерела налаштувань виключають project settings (settings)
- Валідація завантаження файлів: імена з DOS-суфіксом або крапкою приймаються, файли з кількома жорсткими посиланнями відхиляються (windows)
- Завантаження файлів до Claude in Chrome з remote та CLI сесій (vscode-ide)
- Редагування, що лишають ввід як `?`, більше не проковтуються та не перемикають панель скорочень (core)
- Зависання під час запуску, коли розширення Claude in Chrome увімкнене, але Chrome не запущено (vscode-ide)
- Затримка ~300 мс, що видавала асинхронний контент (вкладки налаштувань, Stats, diff-перегляди) (core)
- Повторне відкриття щойно зупиненої фонової сесії не починає порожньої розмови під тим самим session id (skills-agents)
- `/loop` більше не приховує сесію від `/resume` після одноразового використання (skills-agents)
- Звуковий термінальний дзвінок для скрінрідерів зберігається після `/terminal-setup` (core)
- Фонові задачі на LLM gateway-автентифікації більше не повертають «Not logged in» після перезапуску демона (env-vars)
- `claude agents` задачі показують причину відмови на видалення замість мовчазної повторної появи (skills-agents)
- `/clear` скидає лічильник вартості сесії — cost у statusline стартує з $0 (core)
- Сторінки налаштування Claude in Chrome відкриваються у браузері на Windows (windows)
- Headless print-mode сесії на Windows не падають при недоступному stdin (windows, cli)
- Заголовки фонових сесій не показують текст відмови моделі назв при посиланні в промпті (skills-agents)
- Фонові агенти, примусово зупинені користувачем, не перезапускаються автоматично і не запускають застарілі промпти (skills-agents)
- Рутини без розкладу не звітують про час наступного запуску в 1 році н.е. (skills-agents)
- Регресія кешування промптів на Bedrock, Vertex, Mantle та Foundry — завершальний блок системного контенту більше не тарифікується як свіжі токени (core)

## Важливі зміни

- Посилено іменування synced-директорій навичок і плагінів на Windows (windows, plugins)
- Покращено продуктивність компонування терміналу та рендерингу (core)
- Покращено звітування результатів фонових агентів — Claude повідомляє стан агентів, що ще виконуються, та чекає на справжнє завершення (skills-agents)
- Попередження про перевищення ліміту індексу пам'яті вимірює лише завантажений контент, виключаючи frontmatter та HTML-коментарі (core)
- Правила дозволів «always allow» зберігаються у корені репозиторію — погодження, видані в git worktree, зберігаються між сесіями та worktree (settings)
- `/usage-credits` питає підтвердження перед надсиланням запиту адміністраторам організації (cli)
- Vim-команди заміни `s` та `S` працюють у NORMAL mode відповідно до поведінки vim (keybindings)
- Оновлено банер Remote Control з описом того, що він робить [VSCode] (vscode-ide)
- Посилено валідацію шляху завантаження файлів у Claude in Chrome (vscode-ide)
