# Реліз 2.1.181 — 2026-06-23

## Нові можливості
- `/config key=value` syntax — встановлення будь-якого налаштування з prompt (категорія: cli)
- `sandbox.allowAppleEvents` — opt-in налаштування для Apple Events на macOS (категорія: settings)
- `CLAUDE_CLIENT_PRESENCE_FILE` — змінна середовища для придушення push-повідомлень (категорія: env-vars)
- Bundled Bun runtime оновлено до 1.4 (категорія: core)
