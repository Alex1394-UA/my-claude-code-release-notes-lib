# Шаблони форматів файлів

Формат таблиць та файлів у KB.

## Загальний формат таблиці

```
| Ідентифікатор | Опис українською | Версія |
|--------------|-----------------|--------|
```

- Ідентифікатор — технічна назва: `--flag`, `VAR_NAME`, `/command`, назва функції
- Опис — українською, без анґліцизмів (див. `references/anglicisms.md`)
- Версія — формат `X.Y.Z`

## Формат з тегами

- `[Win]` — Windows-специфічне (додай до опису в основній категорії)
- `[ЗАСТАРІЛО]` — замість видалення; можна також ~~закреслити~~
- `[ВИДАЛЕНО]` — для повністю вилучених можливостей

Приклад:
```
| PowerShell tool rollout | PowerShell tool progressive rollout; opt in/out з `CLAUDE_CODE_USE_POWERSHELL_TOOL` [Win] | 2.1.111 |
| ~~`/vim`~~ | [ВИДАЛЕНО] — перемикайте через `/config` → Editor mode | 0.2.34, 2.1.92 |
```

## Структура файлу категорії

Кожен файл категорії починається з заголовка `# Назва категорії`, далі секції `## Підрозділ` з таблицями.

### Базові секції (без версійного суфікса)

Для перших, незмінних записів:

```markdown
# Назва категорії

> Опис призначення категорії (необов'язково)

## Підрозділ

| Можливість | Опис | Версія |
|-----------|------|--------|
| `identifier` | Опис | — |
```

- Версія `—` означає "завжди існувало" або "точна версія невідома"

### Версійні секції

Для нових записів конкретної версії:

```markdown
## Підрозділ (X.Y.Z)

| Можливість | Опис | Версія |
|-----------|------|--------|
| `identifier` | Опис | X.Y.Z |
```

- Нові записи додавай в кінець **відповідного підрозділу**, не в кінець файлу
- Якщо підрозділу ще немає для цієї версії — створи його після останнього запису цієї секції

## Формат мета-файлів

### meta.md

```markdown
last_processed: X.Y.Z
last_updated: YYYY-MM-DD

## Processing History

| Date | Version | Categories Updated | Notes |
|------|---------|--------------------|-------|
| YYYY-MM-DD | X.Y.Z | cat1, cat2, cat3 | ~N записів додано, N депрекацій |
```

### index.md

```markdown
# Індекс бази знань Claude Code

> Останнє оновлення: YYYY-MM-DD | Остання версія: X.Y.Z

## Категорії

- [Назва](categories/file.md) — Короткий опис
```

- Заголовок index.md **завжди** оновлюється (дата + версія)
- Список категорій оновлюється лише при додаванні нової категорії

## Формат снапшоту релізу

Файл `docs/kb/releases/YYYY-MM-DD_vX.Y.Z.md`:

```markdown
# Реліз X.Y.Z — YYYY-MM-DD

## Нові можливості
- bullets з новими фічами

## Виправлення
- bullets з виправленнями

## Важливі зміни
- bullets з breaking changes (якщо є)
```

## Формат записів: типові шаблони

### CLI прапорець
```
| `--flag` | Опис українською | X.Y.Z |
```

### Змінна середовища
```
| `VAR_NAME` | Опис українською | X.Y.Z |
```

### Settings ключ
```
| `setting.key` | Опис українською | X.Y.Z |
```

### Slash команда
```
| `/command` | Опис українською | X.Y.Z |
```

### Виправлення
```
| Назва fix | Виправлено [що] | X.Y.Z |
```
Назва fix — короткий опис, може включати контекст (напр. "Bash permission bypass fix", "Windows terminal fix").

### Managed/Enterprise
```
| `policy.key` | [Managed] Опис | X.Y.Z |
```

### Мультиверсійні записи
```
| `identifier` | Опис | X.Y.Z, X.Y.Z+1 |
```
Коли фіча змінювалася в кількох версіях — список версій через кому.
