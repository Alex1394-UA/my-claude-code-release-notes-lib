# Словник анґліцизмів та українських замін

## Гrep-патерн для виявлення

Використовуй цей патерн для пошуку potential анґліцизмів у файлах категорій:

```
grep -rnP '\b(invoke|match|strip|drop|skip|trigger|report|track|sync|merge|flush|fetch|parse|render|stream|resolve|retry|load|dump|scope|stage|batch|route|proxy|reset|mount|spawn|loop|wrap|fallback|worker|daemon|crash|fix|break|catch|pass|push|pull|cache|block)-[а-яіїєґ]+(ся)?\b' docs/kb/categories/
```

## Прийняті Ukr IT-позички

Ці слова є нормальними українськими IT-термінами — **не виправляти**:

кешувати, парсити, рендерити, клонувати, форкнути, крашити, блокувати, монтувати, дебажити, комітити, проксити, стрімити, білдити, деплоїти, релізити, фіксити, стагувати, дампити, логувати, патчити, мігрувати, рефакторити, ротувати, скіпати, трігерити, трекати, флушити, фетчити, дропати.

## Контекст

Анґліцизм — це слово що поєднує англійський корінь з українським закінченням через дефіс, створюючи штучний гібрид. Наприклад:
- ❌ "Claude invoke-є команду" → ✅ "Claude викликає команду"
- ❌ "фіче match-ила pattern" → ✅ "фіча збігала з pattern"

Складні терміни що не мають короткого українського еквівалента (напр. "cache-miss", "fallback-model") використовуються як technical identifiers — вони не є анґліцизмами у цьому контексті.
